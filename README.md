# Lyupang — 국내 주식 데이터 수집기

윈도우 PC에 저장한 키움증권 인증정보를 이용해 과거 일별 시가·고가·저가·종가·거래량을 CSV로 저장하는 첫 개발 버전입니다. 주문 기능은 없습니다. 전략 학습·재무 분석·뉴스 분석·매매는 아직 구현하지 않았습니다.

## 0.2.0 — 여러 종목의 학습 사례와 재무·공시 연결 준비

**RESEARCH.cmd**를 실행하면 기본 예시 종목 3개(삼성전자 005930, 현대차 005380, NAVER 035420)의 자료와 비교 사례를 준비합니다. 예시 종목은 연결 검증용이며 투자 추천이나 시장 전체를 대표하는 표본이 아닙니다. 기존 CSV가 동일한 기간·수정주가 기준이고 SHA-256·행 수·날짜 검사를 통과하면 다시 조회하지 않습니다. 기존 결과는 덮어쓰지 않습니다.

결과는 `%LOCALAPPDATA%\Lyupang\research`의 실행별 새 폴더에 저장되고, 윈도우 브라우저에서 로컬 파일 `report.html`을 엽니다. 서버나 localhost 접속은 필요 없습니다. 일부 종목이나 DART가 실패해도 성공한 자료는 유지하고, `batch.json`은 `partial` 상태, 프로그램은 종료 코드 2로 표시합니다. 모든 종목·요청 자료·비교 사례가 준비됐을 때만 종료 코드 0입니다.

- `features.csv`: 관찰일까지의 과거 5·20·60개 일봉 가격 변화, 이전 20개 일봉의 평균 거래량 대비 비율, DART 연결 시 이전 7일 공시 건수. 가격 자료 이용 가능 시각은 다음 날 00:00 KST로 기록합니다.
- `future_outcomes.csv`: 관찰 다음 일봉의 시가부터 이후 5·20·60개 일봉 마지막 종가까지의 가격 변화와 구간 고가·저가입니다. 이 값은 미래 결과이므로 **예측 입력에 넣지 않습니다**. 관찰 기간이 아직 지나지 않았으면 `pending`, 거래량 0·상한값 등 품질 문제가 있으면 `quality_issue`로 남깁니다.
- 이 관찰 구간들은 학습 사례 비교를 위한 것이며 매매 보유 기간을 고정하지 않습니다. 수수료·세금·슬리피지가 포함된 전략 수익률이 아닙니다. 겹치는 구간은 독립 표본이 아니므로, 이후 시계열 검증 때 겹치는 구간 제거가 필요합니다.

### 금융감독원 OpenDART 연결

사용자는 DART 인증키가 아직 없다고 확인했습니다. [OpenDART](https://opendart.fss.or.kr/)의 **인증키 신청/관리 → 인증키 신청**에서 발급받으세요. 키움의 실전 인증키와는 별개입니다.

1. 새 버전 폴더에서 **DART_SETUP.cmd**를 실행합니다.
2. 발급받은 40자리 DART 키를 그 창에 직접 입력합니다. 입력은 표시되지 않습니다.
3. 기업개황 조회로 검증한 뒤 윈도우 보안 저장소에 저장합니다. 채팅·코드·일반 설정 파일에는 키를 넣지 않습니다. 기존 정상 키는 재입력 없이 확인하고 유지합니다. `--replace`는 검증된 새 키로 교체할 때만 사용합니다.
4. **RESEARCH.cmd**를 실행합니다. 기업 고유번호, 공시 접수일·보고서명·원문 링크, 직전 사업연도의 연간 재무제표를 수집합니다. 연간 재무제표는 연결(CFS)이 없을 때만 별도(OFS)로 조회합니다.

DART 키가 없거나 읽기 실패하면 연결 대기로 구분합니다. ‘공시 없음(0건)’으로 만들지 않습니다. 공시 목록은 정정 보고서를 포함한 전체 제출 건을 페이지별로 받고 접수번호를 구분합니다. 시각 정보가 없는 같은 날 공시는 과거 정보 계산에서 제외합니다. 재무 API의 현재 수치는 이후 정정됐을 수 있어 별도 JSON에 저장하고, **과거 예측 입력에는 넣지 않습니다**. 원문·공개 시점 검증을 끝내기 전까지 과거 정보로 인증하지 않습니다. 공시 제목이나 가격 변화만으로 상승 원인을 입증하지 않습니다.

키는 로컬 `keyring`의 `Lyupang/OpenDART` 항목에서 사용합니다. 별도로 설정된 클라우드 `DART_API_KEY`도 지원하지만, 윈도우 키 등록을 위해 클라우드에 같은 키를 중복 입력할 필요는 없습니다. 네트워크 요청은 HTTPS의 고정 OpenDART 호스트로만 보내며 인증키가 든 URL과 원문 오류를 출력하지 않습니다. 키가 실려 다른 주소로 이동하지 않도록 리디렉션을 따르지 않습니다.

새 기능은 가상 응답으로 검증합니다. 여러 종목·DART의 실제 수집과 새 윈도우 실행기는 아직 PC에서 확인해야 합니다. 기존 단일 종목 수집은 2026-10-27 사용자 PC에서 삼성전자 729거래일(2023-10-26~2026-10-26), 2페이지, CSV 저장까지 확인됐습니다.

```powershell
.\RESEARCH.cmd --codes 005930,005380,035420
.\RESEARCH.cmd --codes 005930 --prices-only
```

현재 `training_ready`, `point_in_time_verified`, `trading_enabled`는 모두 false입니다. 시장 전체·상장폐지 종목의 편향 처리, 거래일 달력 대조, 사업·뉴스 본문 분석, 원문 기반 재무 시점 검증, 모델 학습, 모의매매와 실전 주문은 남아 있습니다.

## 윈도우에서 시작하기

준비물: 기존에 연결 검증을 마친 `kwcli 1.0.3`, 계좌 별칭 `kiwoom-real`. 인증키를 새로 입력하거나 파일로 복사하지 않습니다.

1. 전달받은 ZIP 파일을 다운로드하고 **모두 추출**하세요.
2. 압축을 푼 폴더에서 **START.cmd**를 실행하세요.
3. 종목코드를 물으면 Enter를 누르세요. 기본 종목은 **005930 삼성전자**입니다. 종목 선정의 투자 의미는 없습니다.
4. 약 3년 전부터 **한국 시간 기준 어제까지** 조회합니다. 이는 자료를 모으는 기간이며 매매 보유 기간이 아닙니다.
5. **수집·저장 완료**와 거래일 수가 표시되는지 확인하세요. 실패나 취소는 성공으로 처리하지 않습니다.
6. **OPEN_DATA.cmd**를 실행하면 결과 폴더가 열립니다. 가장 최근 실행 폴더의 `daily.csv`와 `manifest.json`을 확인하세요.

결과는 `%LOCALAPPDATA%\Lyupang\data`에 실행별 새 폴더로 저장됩니다. 기존 수집 결과는 덮어쓰지 않습니다. `daily.csv`는 엑셀에서 열 수 있는 UTF-8 BOM 형식입니다. 엑셀은 종목코드의 앞자리 0을 자동 제거할 수 있으므로, 분석에 사용할 때 종목코드 열을 텍스트로 읽으세요.

START.cmd는 Windows의 `whoami` 결과를 자식 프로세스의 USERNAME에 적용합니다. 이는 kwcli 1.0.3이 짧은 계정 이름 `PC`를 잘못 해석해 임시파일 권한을 지정하던 문제의 검증된 보정입니다. 시스템 전체 환경변수, 윈도우 보안 정책, 기존 키움 프로그램 코드는 바꾸지 않습니다.

기존 도구가 기본 위치에 설치됐다고 가정합니다. Python 위치가 다르면 `UV_TOOL_DIR` 또는 `LYUPANG_PYTHON`으로 실제 kwcli 파이썬 위치를 지정할 수 있습니다. 위치를 찾지 못하면 실행 창에 표시된 메시지를 알려주세요. 관리자 권한으로 실행할 필요는 없습니다.

## 수집 내용과 한계

- API는 키움 `ka10081`, `/api/dostk/chart`로 고정되어 있습니다. KRX 종목코드 6자리만 받습니다.
- 연속조회 키를 따라 과거 자료를 읽습니다. 페이지는 0.6초 이상 간격으로 요청합니다. 반복 키·빈 연속조회·역행 날짜·상충하는 중복·페이지 한도 초과는 실패입니다.
- 동일한 날짜의 같은 값은 한 번만 저장합니다. 날짜는 과거순으로 정렬합니다. 거래량은 주, 가격은 원, 거래대금은 **백만원**입니다.
- 키움 가격의 부호는 방향 표시로 처리해 가격 절댓값을 저장합니다. 거래량이 0인 날과 알려진 상한값 `4294967295`인 날은 별도 표시합니다. 수치를 임의 보간하지 않습니다.
- 수정주가가 기본입니다. 기준일까지의 액면분할 등 권리 변동을 반영할 수 있으므로 `manifest.json`에 기준일과 수집 시각을 기록합니다. 이 값은 과거 당시 시장 참여자가 알았던 정보와 동일하지 않을 수 있습니다.
- `manifest.json`은 실제 시작·종료일, 행 수, 조회 종료 이유, 품질 표시, CSV SHA-256을 기록합니다. 공급자 기록이 끝나면 요청 시작일보다 실제 시작일이 늦을 수 있습니다.
- **거래소 휴장일 달력과 대조한 누락 검증은 아직 없습니다.** 상장 전, 거래정지, 휴장과 공급자 누락을 자동으로 구별하지 못합니다. 조회를 정상 종료했다는 사실을 모든 거래일의 완전성으로 해석하지 마세요.
- 재무·공시·뉴스의 공개 시점, 상장폐지 종목, 시장 전체 종목 편향은 이후 단계입니다. 현재 결과는 학습·백테스트 준비가 끝난 데이터로 표시하지 않습니다.
- 인증키, 토큰, 계좌 잔고, HTTP 헤더와 원문 오류는 결과에 저장하지 않습니다. 인증정보는 기존 SDK가 윈도우 자격 증명 저장소에서 사용합니다.

## 기간·종목 변경

압축을 푼 폴더에서 PowerShell을 열어 실행할 수 있습니다. 기본값 대신 원하는 종목·기간을 지정하세요. 종료일은 한국 시간 기준 어제까지 허용됩니다.

```powershell
.\START.cmd --code 005930 --start 2023-01-01 --end 2026-10-26
```

다른 별칭은 `--profile`, 원주가는 `--unadjusted`, 출력 폴더는 `--output`으로 지정합니다. 한 번에 한 종목만 수집하는 버전입니다.

## 개발·검증

Python 3.13, uv를 사용합니다. 기존 체크아웃을 사용하며, 클라우드 작업은 이미 격리되어 있으므로 요청 없이 Git worktree를 만들지 않습니다.

```sh
cd /workspace/Lyupang
uv sync --frozen --python 3.13
uv run --frozen python -m unittest discover -s tests -v
uv run --frozen python collect.py --help
uv run --frozen python tools/build_bundle.py
```

실제 수집은 등록된 IP에서 실행해야 합니다. 클라우드 직접 연결은 이전 인증 요청에서 차단됐습니다. 로컬 테스트는 가상 HTTP 응답을 사용하며, 테스트 통과는 새 윈도우 기능의 실제 수집 성공을 뜻하지 않습니다. 기존 단일 종목 수집은 사용자 PC에서 729개 일봉 저장까지 검증됐습니다.

공식 자료: [API 가이드](https://openapi.kiwoom.com/guide/apiguide), [공식 배포 도구](https://pypi.org/project/kwcli/1.0.3/). 요청·응답 스키마는 배포본의 `kiwoom/_data/kiwoom_api_spec.json`을 확인했습니다.
